# Чат-бот с живым общением

Проблема бизнеса: Менеджеры тратили рабочее время на ручные ответы по частым вопросам. В нерабочие часы бизнес упускал заявки.

Бот работает с клиентами по базе заказчика: разбирает запрос, предлагает варианты из ассортимента и записывает на услугу без участия человека.

Клиенты получают ответы круглосуточно. Часть диалогов бот доводит до покупки. Менеджеры подключаются только к сложным задачам.

В этом образце магазин называется «ТеплоДом». Чтобы просто посмотреть, как бот отвечает, достаточно открыть демо-страницу на своём компьютере.

## Как попробовать

Нужны Windows и программа [Node.js](https://nodejs.org/) (кнопка LTS). При установке жмите «Next».

1. На этой странице нажмите зелёную кнопку **Code** → **Download ZIP** и распакуйте архив.
2. Скопируйте файл `.env.example` и назовите копию `.env`. Это файл настроек. Он остаётся только у вас на компьютере.
3. Чтобы бот отвечал, в `.env` в строке `PROXYAPI_KEY=` вставьте ключ из кабинета [ProxyAPI](https://proxyapi.ru/). Без ключа страница откроется, но ответы не пойдут.
4. Откройте папку проекта. В адресной строке Проводника напишите `cmd` и нажмите Enter.
5. Введите `npm install` и дождитесь окончания (первый раз несколько минут).
6. Введите `npm start`.
7. Откройте в браузере адрес [http://localhost:3000](http://localhost:3000). Справа будет чат демо-магазина. Напишите, например, про товар или запись на услугу.

Чёрное окно не закрывайте, пока смотрите демо.

Подключить того же бота к своему сайту или сообществу ВКонтакте можно отдельно. Для первого знакомства это не нужно. Если хотите поставить к себе — напишите, проведу по шагам.

## Как пользоваться

1. Клиент пишет в чате на сайте.
2. Бот отвечает по материалам магазина: товары, цены, условия, частые вопросы.
3. Если вопрос вне базы или клиент просит человека, менеджеру уходит короткое уведомление.
4. Менеджер отвечает клиенту в том же чате на сайте.
