# Чат-бот с живым общением

Менеджеры тратили рабочее время на ручные ответы по частым вопросам. В нерабочие часы бизнес упускал заявки.

Бот работает с клиентами по базе заказчика: разбирает запрос, предлагает варианты из ассортимента и записывает на услугу без участия человека.

Клиенты получают ответы круглосуточно. Часть диалогов бот доводит до покупки. Менеджеры подключаются только к сложным задачам.

Демо-магазин в этом репозитории — «ТеплоДом». Виджет ставится на сайт. Тот же бот отвечает в сообщениях сообщества ВКонтакте.

## Установка и запуск

Нужен Node.js 18 или новее.

```cmd
copy .env.example .env
```

Заполните `.env` (ключи не коммитьте):

| Поле | Зачем |
|---|---|
| `PROXYAPI_KEY` | доступ к модели ответов |
| `VK_GROUP_TOKEN`, `VK_GROUP_ID` | ответы в сообществе ВКонтакте |
| `VK_MANAGER_IDS` | кому писать, если нужен человек |

```cmd
npm install
npm start
```

Откройте http://localhost:3000 — демо-сайт с виджетом.

В сообществе ВКонтакте включите Long Poll API и событие «Входящее сообщение». Напишите сообществу в личные сообщения — бот ответит по той же базе.

### Встройка на свой сайт

```html
<link rel="stylesheet" href="https://ВАШ-БЭКЕНД/widget.css" />
<script
  src="https://ВАШ-БЭКЕНД/widget.js"
  defer
  data-api="https://ВАШ-БЭКЕНД"
  data-title="Поддержка"
  data-subtitle="Название компании"
></script>
```

Статику из `public/` можно выложить отдельно. Сервер (`npm start`) должен работать постоянно: иначе не будут приходить сообщения ВКонтакте.

## Как пользоваться

1. Положите в проект файлы с товарами, ценами, условиями и частыми вопросами.
2. Клиент пишет на сайте или в сообществе. Бот отвечает только по этим материалам.
3. Если вопрос вне базы или клиент просит человека, менеджеру уходит короткое уведомление.
4. Менеджер отвечает клиенту на сайте, не в служебном уведомлении.
