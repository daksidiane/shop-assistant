Как проверить решение

  1. Скопируйте .env.example → .env и вставьте ключи ProxyAPI и VK.
  2. Запустите npm start и откройте эту страницу.
  3. Напишите в виджет: «Помогите выбрать кондиционер на 25 м²».
  4. Параллельно напишите в ЛС сообщества ВК — Long Poll обработает сообщение тем же ИИ.

Для Netlify загрузите папку public/ как статический сайт и укажите URL бэкенда в widget.js (data-api). Бэкенд с Long Poll нужен на Node-хостинге.
